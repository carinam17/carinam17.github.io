What does a medical license cost, state by state?

Telehealth physicians need a license in every state where their patients are. At Medspoke, a telehealth licensing company, I built a Python tool that estimated what each new license would cost and helped decide where a doctor should apply first. This is that tool, rebuilt for the web.

      how it's built

      The fee tables and rules live in Python (fees.py, estimate.py). A build script writes them to the data file this page reads, and a check runs every state through both versions to confirm the totals match: 3,264 combinations, zero differences.

      Read the Python →

      what I fixed from the original

      • The total missed fees it had calculated: license registration, the Uniform Application, transcript, ECFMG and NPDB fees, and Arkansas's verification fee.
      • Renewal cycles: New Mexico and Washington reported both a 3-year and a 2-year cycle.
      • Data: one state's fee disagreed between two files, and one table had an unknown state code.
      • Input: a mistyped state code crashed the script. The web version only offers valid states.
